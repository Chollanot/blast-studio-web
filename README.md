# Blast-YOLO Studio (Public Demo)

Research demonstration of multi-task deep learning for 24-class blastocyst grading.

**RESEARCH AND EDUCATION USE ONLY.** This web demo runs on a shared cloud server.
Uploaded images are processed remotely. **Do NOT upload identifiable patient images or any data containing PHI.**
For real clinical use, contact the authors for the local installer.

## Live demo
https://blast-studio-web.streamlit.app

## Reference
Kanitwithayanun C et al. Blast-YOLO: A Novel Multi-Task Deep Learning
Architecture for Explainable Blastocyst Grading in IVF Laboratories.
Healthcare Analytics (submitted).
